London Bike Rides Analysis 
Project Overview
This project provides a comprehensive analysis of London's bike-sharing data to identify how weather conditions and seasonal trends impact ridership. The dashboard translates raw data into actionable insights for urban planning and resource allocation.

Key Features & Visualizations
1. Environmental Impact Heatmap: Analyzes the relationship between Temperature (°C) and Wind Speed (kph) to identify the "sweet spot" for maximum bike usage.

2. Dynamic Moving Averages: Features a user-adjustable parameter for Moving Average Duration (e.g., 19 weeks) to smooth out short-term fluctuations and highlight long-term ridership trends.

3. Total Ridership KPI: A high-level summary showing 1,522,228 total rides within the selected timeframe.

4. Interactive Time Filtering: Allows users to drill down into specific date ranges between 2015 and 2017 to observe seasonal changes.

Technical Skills Demonstrated
1. Calculated Fields: Implemented advanced logic for dynamic moving averages and weather binning.

2. Parameters: Created interactive controls for users to define the granularity of the trend lines.

3. Data Visualization: Utilized heatmaps, line charts with dual-axis integration, and clear KPI indicators for effective storytelling.

4. Sheet Interactivity: Used "Drag and Hold" selection tools to highlight specific data points across multiple views.

Data Source
The dataset used for this analysis includes weather-related variables and bike-sharing counts from the London area. It covers timeframes from early 2015 through early 2017.
